# Roadmap

This roadmap describes development intentions, not delivery promises.

## Next release

- validate configuration values and improve error messages;
- add issue templates for bugs, features and documentation;
- add more layout and highlight tests;
- document accessible contrast and legibility checks;
- improve Windows, macOS and Linux usage notes;
- provide reviewed Portuguese and English examples.

## Later

- support additional social media dimensions;
- add an optional PNG export path using open-source dependencies;
- add reusable template definitions;
- add a local preview interface for non-technical users;
- accept and review external templates without proprietary assets;
- evaluate subtitle and motion integrations as separate tools.

## Non-goals

- collecting user content or analytics;
- bundling proprietary fonts, images or client assets;
- depending on a paid external API for core generation;
- promising platform reach or marketing performance.
